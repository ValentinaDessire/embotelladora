# Embotelladora Thomsom · Registro de llenado

Pequeña aplicación web para una embotelladora: registra cada jornada de llenado de botellones (fecha, hora y cantidad) y muestra el historial de registros.

> Proyecto académico · Cátedra Programación Web

## Funcionalidades

- Formulario para registrar un llenado: fecha, hora y cantidad de botellas.
- Historial de registros en una tabla.
- Envío y consulta de datos con PHP; interacción en el navegador con JavaScript.

## Tecnologías

`HTML5` · `CSS3` · `JavaScript` · `PHP`

## Estructura

```
PW/
├── index.html      # Formulario e historial
├── registrar.php   # Guarda un nuevo registro
├── historial.php   # Devuelve el historial
├── main.js         # Lógica del formulario
└── styles.css      # Estilos
```

## Cómo ejecutarlo

1. Necesitas PHP instalado (o XAMPP).
2. Desde la carpeta `PW/` ejecuta: `php -S localhost:8000`
3. Abre `http://localhost:8000` en el navegador.
